# Raw OEWS annual files

Drop the BLS OEWS annual files here as downloaded (zip or extracted, any mix).
One subfolder per year is fine but not required; the loader will read the year
from the file name (oes97..oes02, oesm03..oesm25).

Most useful, in priority order:
1. "All data" files (oesmYYall) for 2011-2025
2. National, state and metro files (nat, st, ma) for every year
3. Industry files (in3/in4) are not needed

These files are not committed to git (see .gitignore).
